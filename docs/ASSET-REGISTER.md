# BUILDORA — Asset Register / جرد الصور المطلوب (Stage A)

**الحالة:** التخطيط فقط؛ لا يدّعي هذا المستند شراءً أو تنزيلًا أو التحقق من ترخيص أي صورة. المصادر المقترحة: أعمال أصلية أو صور من Unsplash/Pexels بعد مراجعة شروط الاستخدام الحالية، مع حفظ رابط المصدر والمؤلف والترخيص لكل أصل مُعتمد. تحفظ النسخ في `assets/images/` محليًا بصيغة WebP/AVIF، ولا Hotlink.

## 1. قائمة المتطلبات

| القسم | نوع الصورة | العدد المستهدف | الشكل | الأولوية |
|---|---|---:|---|---|
| Home Hero | لقطة معمارية رئيسية قوية | 1 | 16:9 أو أوسع، Overlay للنص | P0 |
| Projects | Thumbnail لكل مشروع | 12 | 4:3 موحد | P0 |
| Project Details | Gallery توضيحية لكل مشروع (الحد الأدنى المخطط) | 24 (صورتان/مشروع) | 4:3 أو نسب مدروسة | P1 |
| Before/After | أزواج متطابقة الزاوية قدر الإمكان | 4 أزواج = 8 صور (اختيار Demo مبدئي) | نفس الأبعاد/المشهد | P1 |
| About | صورة هندسية/فريق بدون انتحال أشخاص | 1–2 | 4:3 / 3:2 | P1 |
| Services | إن احتاجت تخطيطات غير الأيقونات | 0–6 | 4:3 | P2، اختياري |
| Fallback | Placeholder هندسي محلي | 1 | SVG أو WebP | P0 |
| Brand | `favicon.svg` أصلي | 1 | Vector | P1 |

**ملاحظة مهمة:** العدد خطة تخطيط لا شرطًا إلزاميًا للدليل؛ يحكم التنفيذ الفعلي جودة الصور وتوافر حقوق استخدامها. لا يجب تصوير Before/After كأنه توثيق لتحول حقيقي إذا كانت الصور من مصادر مختلفة؛ الأفضل زوج صور مُنشأ/مملوك بغرض التوضيح مع وسم واضح. لا صور أشخاص توحي بأنهم فريق الشركة الحقيقي.

## 2. حقول سجل الأصل لكل صورة قبل التوريد

- `assetId`، `filePath`، `section`/`projectId`، `sourceUrl`، `creator`، `licenseName`، `licenseVerifiedAt`، `attributionRequired`، `width`، `height`، `format`، `altAr`، `isDemo`.
- يجب أن تكون حقوق الاستخدام مناسبة لإعادة النشر في Demo عام، وأي نسب مطلوب يُذكر بوضوح. إذا تعذر توثيق الحقوق لا تعتمد الصورة.

## 3. قواعد التحسين

- صورة Hero: نسخة مضغوطة مناسبة، لا `loading="lazy"` فوق الطيّة، مع دعم responsive sizes إن أمكن.
- صور تحت الطية: `loading="lazy"` مع width/height لتجنب CLS و`object-fit:cover` للبطاقات.
- Gallery: فتح نسخة مناسبة للدقة وتكبير Lightbox؛ لا استخدام الصورة المصغرة الصغيرة بوصفها أصلًا مكبرًا.
- Fallback عند فشل التحميل أو فقدان صورة ثانوية، وعدم عرض سلايدر Before/After إذا غاب أحد الطرفين.
- الـ Alt يصف الصورة، وليس حشوًا للكلمات المفتاحية. الصور الزخرفية لها Alt فارغ عندما يلزم.
